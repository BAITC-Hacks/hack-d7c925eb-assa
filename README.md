# Career Quest — разбор датасета

Репозиторий содержит исходный синтетический датасет Career Quest и
воспроизводимый аналитический пайплайн без внешних зависимостей.

## Состав

- `career_quest_dataset/` — исходные JSON/CSV-файлы и описание схемы;
- `scripts/analyze_dataset.py` — проверка связей, расчёт метрик, дефицитов
  навыков и рекомендаций;
- `analysis/REPORT.md` — итоговый разбор с ключевыми выводами;
- `analysis/summary.json` — машинно-читаемая сводка;
- `analysis/event_metrics.csv` — показатели мероприятий;
- `analysis/employee_skill_gaps.csv` — дефициты навыков сотрудников;
- `analysis/recommendations.csv` — до пяти рекомендаций на сотрудника.

## Запуск

```bash
python scripts/analyze_dataset.py
```

Скрипт использует дату среза `2026-10-01`, указанную в документации набора,
и перезаписывает файлы в `analysis/`. Для запуска достаточно Python 3.10+.

## Логика рекомендаций

Рекомендации строятся для карьерной цели сотрудника, а если цель не задана —
для текущей роли и грейда. Кандидат должен:

1. быть добровольным мероприятием;
2. подходить по целевой роли и грейду;
3. иметь выполненные предварительные требования;
4. развивать хотя бы один дефицитный навык;
5. быть доступным самостоятельно или иметь будущую сессию.

Повтор уже завершённого мероприятия исключается, кроме регулярного клуба
`EV_036`. Приоритет получают мероприятия, закрывающие критические навыки,
больший суммарный дефицит и больше дефицитов за меньшее число часов.
